## Mot-symbole

Reconstruction haute définition de la petite image de référence `assets/images/app_launcher_icon.png`.
Prompt : conserver exactement le mot OUTBUSTER, capitales très condensées avec la flèche
dans OUT ; OUT blanc et BUSTER jaune citron #DFFF00 ; sous-titre blanc espacé L’AUTRE CINÉMA.
Format horizontal transparent, lettres nettes, rendu plat 2D, sans ombre, dégradé, scène,
maquette, cadre ou texte supplémentaire. Identité existante conservée, pas de nouvelle marque.
